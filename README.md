# Resume & Cover Letter Customizer with DeepSeek API


A Streamlit web application that uses DeepSeek API to optimize resumes and generate tailored cover letters for job applications.

## Features

- **Resume Optimization**:
  - ATS-friendly formatting
  - Keyword enhancement based on job descriptions
  - Achievement highlighting
  - Formatting cleanup

- **Cover Letter Generation**:
  - Personalized for specific job applications
  - Customizable tone (Professional, Enthusiastic, etc.)
  - Adjustable length (Short, Medium, Long)
  - Incorporates relevant skills from your resume

- **File Support**:
  - Upload resumes as TXT, PDF, or DOCX
  - Download optimized versions as TXT or PDF

## Prerequisites

Before you begin, ensure you have:

- Python 3.7 or higher
- A [DeepSeek API key](https://platform.deepseek.com/)
- Basic knowledge of Python and Streamlit
